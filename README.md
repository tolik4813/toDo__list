# ToDo List

A modern, responsive To-Do List web application built with vanilla JavaScript, HTML, and CSS. Features local storage persistence and an intuitive user interface for efficient task management.

## Features

- ✅ Add new tasks
- ✅ Mark tasks as complete/incomplete
- ✅ Delete tasks
- ✅ Data persistence using LocalStorage
- ✅ Responsive design
- ✅ Clean and modern UI
